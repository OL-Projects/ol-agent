# OL

**An agent that cannot claim what it has not proven.**

OL is a personal agent that runs on your own Mac. What makes it different is not that it can act — it is
that a unit of work closes only when that unit's own verifier passes.

- A document is rendered to pixels, page by page, and measured for clipping and ink coverage.
- Its subtotal + GST 5% + QST 9.975% is recomputed against the printed total, to the cent.
- A deploy is accepted only when the served bytes hash-match the built bytes. A `200` is not proof.
- A mismatch means refusal, with the reason recorded — not a warning.

Every unit carries the highest proof tier it actually reached:

```
source · wired · tested · built · installed · runtime-proven · device-proven
```

It may not be described above that tier — not in a status line, not in a summary, not to you.
